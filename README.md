# Fleet Odometer & Maintenance Tracker APK Releases (v1.3.0)

Repository resmi distribusi berkas APK pembaruan aplikasi driver armada **Fleet Odo & Service Tracker** (Versi 1.3.0 dengan Fitur Koreksi Odometer & Audit Trail Sheet `KOREKSI KM`) untuk operasional HUB Kediri.

Rilis APK terbaru tersedia pada halaman [GitHub Releases](https://github.com/deckyp5758-eng/aplikasi-HUB/releases). Aplikasi driver menggunakan repository ini sebagai sumber distribusi APK publik dan tetap terhubung ke backend Apps Script canonical H033.
